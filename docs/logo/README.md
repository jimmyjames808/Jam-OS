# The Jam OS logo

Seven drupelets, like a raspberry: separate parts that make one whole, as
Jam OS's drivers and services are separate processes. The centre is the
darkest berry; gold sits at the bottom right.

| File | What |
|---|---|
| `jamos-mark.svg` | the mark, transparent: the master |
| `jamos-mark-<N>.png` | the mark at 16, 32, 48, 64, 128, 256, 512 and 1024 px, transparent |
| `favicon.ico` | 16, 32, 48 and 64 px |
| `jamos-lockup-light.png` | the mark and the `Jam OS` wordmark, for light backgrounds, transparent |
| `jamos-lockup-dark.png` | the same for dark backgrounds |
| `jamos-social.png` | 1280 x 640 for link previews (GitHub's social preview) |

Colours: berries `#8E1B3A` (centre), `#A9244A`, `#C8284F`; gold `#D9A032`
(`#B8841F` for text on light backgrounds); dark `#1E1A1D`; cream
`#F6EFE6`. The wordmark is `Jam OS` set in JetBrains Mono Regular (the OS's own
monospace, `third_party/jetbrains-mono`), `Jam` in the text colour (cream on
dark, dark on light) and `OS` in gold, its cap height centred on the mark. The
lockups and the social image match the last frame of the boot splash.
