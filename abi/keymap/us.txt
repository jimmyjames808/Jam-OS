# A keyboard layout: US (AU keyboards are US). tools/genkeymap.py turns
# it, with the keys in keys.txt, into user/lib/keymap_us.c: the C table
# Jam OS's own programs decode keys with (<keymap.h>), and the XKB text
# keymap the compositor sends Wayland clients (wl_keyboard.keymap), whose
# first line names this layout. `make keymap` makes it again; `make
# check` fails if it is stale.
#
# The format, one statement a line ('#' starts a comment):
#   layout <name>            the layout's name: [a-z0-9_-], at most 15
#                            characters; the keymap's first line carries it
#   description <text>       what XKB's group name shows ("English (US)")
#   <key> <type> <level 1> [<level 2>]
#       key      a key's name from keys.txt
#       type     how the modifiers pick a level:
#                  ONE_LEVEL   one keysym whatever is held
#                  TWO_LEVEL   Shift picks level 2
#                  ALPHABETIC  Shift or Caps Lock picks level 2 (both: 1)
#                  KEYPAD      Num Lock picks level 2; Shift changes
#                              nothing (as hid's US layout has always done;
#                              XKB's usual keypad lets Shift undo Num Lock)
#       level    an X keysym by name (XKB's names: exclam, KP_7, Return;
#                a single ASCII digit or letter stands for itself), the
#                level 2 one for every type but ONE_LEVEL
# Every key of keys.txt this layout gives a keysym is listed; a key left
# out is no key in this layout. Ctrl, Alt and Super pick no level: they
# go to the program with the key, as hid's events do today.
#
# The character a keysym types (the C table's code point; XKB clients ask
# xkbcommon) is the generator's rule, the same for every layout: Latin-1
# keysyms are their own code point, Unicode keysyms (0x01000000 + code
# point) theirs; Return and KP_Enter type '\n', Tab and ISO_Left_Tab '\t',
# BackSpace '\b', Escape 0x1b; the keypad's digits, operators and
# separator their ASCII character; everything else (the arrows, Delete,
# the function keys, the modifiers) none. That is hid's US layout exactly:
# the utest checks every key it maps against the driver itself.
