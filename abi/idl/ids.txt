# The protocol id registry: every id a message's second word may carry in
# its top 16 bits (an IDL request's ordinal is (id << 16) | method), the
# .idl protocols' and the hand-written ones' alike, so that no two
# protocols share one and a message sent to the wrong server is refused
# (ERR_NOT_SUPPORTED) instead of taken for one of its methods.
#
# tools/genidl.py reads this file: it refuses an .idl protocol that isn't
# listed here under its name, id and file, a line naming an .idl that
# doesn't define it, an id or a name listed twice, and a file that doesn't
# exist; and it writes the list into drivers/include/idl/common.h
# (IDL_ID_<NAME>). A new protocol takes a free id here first.
#
# One line per id: <id> <name> <where> [# what], where <where> is the
# protocol's .idl, or the header of one that stays hand-written (its id is
# the top half of the word after its txid: a magic number's, for some).
