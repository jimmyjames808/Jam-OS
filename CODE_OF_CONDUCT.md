# Code of conduct

Jam OS follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- Be respectful and welcoming, whatever someone's background, identity or
  experience.
- Discuss the work, not the person. Criticism of code and designs is
  welcome; personal attacks, harassment, insults and discriminatory
  language are not.
- Don't publish anyone's private information.
- Assume good faith, and accept that the maintainer decides what goes into
  the project.

This applies in the repository's issues, pull requests, discussions and
reviews.

## Reporting

Report unacceptable behaviour to the maintainer privately, through GitHub
(for example a private security advisory on this repository, which only
the maintainer can read), or with GitHub's own **Report abuse** tool. All
reports are read and handled in confidence.

## Consequences

The maintainer may remove, edit or reject comments, commits, issues and
pull requests that break this code, and may block people who keep breaking
it.
