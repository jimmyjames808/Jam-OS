# libc-test's functional and regression sets, run by the libc-test program
# (runner.c; tools/libc-test.sh): the tests that are expected not to pass,
# each with its reason. One line a test: `set/name kind: reason`.
#   enosys   by design (docs/M13-PLAN.md "What M13 is not": SysV IPC)
#   limit    a known limit of Jam OS or of this port
#   bug      a bug of ours in user/posix, not fixed yet (a one-line description)
#   pending  waits for another track (named in the reason)
#   skip     not built: the test needs dynamic linking (M14.5)
# The list is exact: a test that passes while listed is a problem (XPASS)
# just as one that fails while not listed (FAIL). Take a line out when its
# reason is gone. Tests whose cause is the same are grouped.

# ---- not built --------------------------------------------------------------------------
functional/dlopen skip: needs dlopen, and Jam OS has no dynamic linking (M14.5)
functional/tls_align_dlopen skip: needs dlopen, and Jam OS has no dynamic linking (M14.5)
functional/tls_init_dlopen skip: needs dlopen, and Jam OS has no dynamic linking (M14.5)
regression/tls_get_new-dtv skip: needs dlopen, and Jam OS has no dynamic linking (M14.5)

# ---- fork: a forked child's descriptors and exec (docs/FORK-PLAN.md) ---------------------------
functional/fcntl pending: its forked children test the parent's record lock on its file, which needs a forked child's descriptors (FORK-PLAN's FL2) and locks told apart by process
functional/vfork pending: its child execs /bin/sh, which needs a forked child's descriptors and exec (FORK-PLAN's FL2, FL3)
regression/daemon-failure pending: its child dup2s a pipe, which needs a forked child's descriptors (FORK-PLAN's FL2)
regression/fflush-exit pending: its child dups a file, which needs a forked child's descriptors (FORK-PLAN's FL2)

# ---- SysV IPC: not provided ---------------------------------------------------------------
functional/ipc_msg enosys: msgget and msgctl are ENOSYS (SysV IPC is not built)
functional/ipc_sem enosys: semget and semctl are ENOSYS (SysV IPC is not built)
functional/ipc_shm enosys: shmget and shmctl are ENOSYS (SysV IPC is not built)

# ---- a POSIX shell: /bin/sh is a stub (simple commands only) until M13.5 --------------------------
functional/popen limit: its second command is a shell script (read; test; kill); /bin/sh is a stub until M13.5; its first needs echo (sbase)
functional/wordexp limit: wordexp runs /bin/sh, which is a stub until M13.5
regression/execle-env limit: runs sh -c with a test ([), and /bin/sh is a stub until M13.5

# ---- waiting for other tracks -----------------------------------------------------------------

# ---- threads ----------------------------------------------------------------------------------
functional/pthread_cancel limit: an asynchronous cancel of a thread in a busy loop never takes effect (signals are delivered at call boundaries only, docs/M13-PLAN.md section 6): the test hangs
functional/pthread_mutex_pi limit: priority-inheritance mutexes need futex PI operations, which Jam OS has not
functional/pthread_robust limit: robust mutexes need set_robust_list, which Jam OS has not (pthread_mutexattr_setrobust is ENOSYS); the test then hangs
regression/pthread-robust-detach limit: robust mutexes need set_robust_list, which Jam OS has not

# ---- files and the system -----------------------------------------------------------------------
functional/sem_open limit: named semaphores publish their file with link() under /dev/shm, whose names are libc's own and take no links (EACCES, user/posix/sys/dev.c; FAT or ext under /data makes no difference); the test then dereferences SEM_FAILED
regression/sem_close-unmap limit: named semaphores publish their file with link() under /dev/shm, whose names are libc's own and take no links (EACCES, user/posix/sys/dev.c); the test then dereferences SEM_FAILED
regression/statvfs limit: / is the namespace root, a list of mounts, not a file system: statvfs("/") reports no blocks

# ---- musl 1.2.6 against a newer libc-test ---------------------------------------------------------
functional/strptime limit: libc-test master tests strptime's %s and a two-digit %z, which musl 1.2.6 does not do (its %s only skips the digits)
functional/socket limit: loopback works now, but the test calls getsockname on a bound stream socket that is not listening yet and connects to the port it reports: Jam OS picks a stream socket's port at listen (B6 notes), so it reports 0; its UDP part sets SO_RCVTIMEO to 1 microsecond, which Linux rounds up to its tick and which here is exact (netstack delivers a loopback datagram a moment after the send); and bin/libc-test's list has no `svc net` (EACCES at the first bind)
