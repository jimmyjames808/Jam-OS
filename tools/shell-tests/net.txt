# `net` and `ping` (tools/ping-test.sh runs this): a plain boot with
# QEMU's e1000e and the network peer (tools/netpeer.py answers ARP and
# ICMP echo for any address on VLAN 21), net.address set in the stick's
# settings. `net` shows the address and the link; `ping 1.1.1.1` goes
# through the gateway and is answered; Ctrl+C stops a ping in the middle;
# `net stats` has the programs' counts and the card's own.
wait 120 Jam OS shell
seen 60 netstack: link up
seen 30 netstack: address 10.2.21.5/24
wait jam>
send net
wait address  10.2.21.5/24, gateway 10.2.21.1
wait DNS      10.2.21.1
wait VLAN 21
wait jam>
send ping 1.1.1.1 -c 3
wait PING 1.1.1.1: 56 data bytes
wait 64 bytes from 1.1.1.1: seq=1 ttl=64
wait --- 1.1.1.1: 3 sent, 3 received, 0% lost; round trip
wait jam>
send ping 10.2.21.174 -c 100 -s 1472
wait 1480 bytes from 10.2.21.174: seq=2
type \x03
wait 10.2.21.174: 2 sent, 2 received
wait jam>
send ping 10.2.21.174 -c 0
wait usage: ping
wait jam>
send net stats
wait pings sent
wait the card's driver:
wait tx frames
wait jam>
send reboot -f
wait reboot: resetting
