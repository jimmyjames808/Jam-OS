# SNTP (tools/sntp-test.sh runs this): a plain boot with QEMU's e1000e,
# the RTC at 2026-01-15 and the network peer's SNTP server
# (tools/netpeer.py --ntp: 2031-02-27 23:06:40 UTC at its start, each
# answer after a forged one the guest must ignore). bin/sntp asks the
# gateway once the DHCP lease is there, ignores the forged replies, has
# the big step confirmed by a second reply and sets the clock: `date -u`
# jumps to 2031 and `date -r` says the network set it; `date -z` keeps
# it; a restarted sntp asks again and finds almost nothing to move; and
# when /data comes back (devmgr killed and started again), init keeps the
# network's time instead of reading the RTC again.
