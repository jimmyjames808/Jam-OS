# posixtest's unix section from the shell: named AF_UNIX sockets through
# /svc/unix (bin/unix, the broker init supervises in shell mode;
# user/posix/sys/unixsock.c): a listener and two connectors, bytes and a
# descriptor over a connection, the backlog, a socket file removed and a
# stale one, a child without /data refused and one with /data read-only
