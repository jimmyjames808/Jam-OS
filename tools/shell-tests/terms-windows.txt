# Terminals as windows (docs/G1-PLAN.md, track T1), once the compositor
# has windows (xdg-shell) and its own input (the boot wiring: serialin
# and the keyboards connected to it, not to the console): booted with
# `comp`, the first terminal opens as a window; `term` opens terminal 2,
# whose window takes the keys (a client's first window does), so `exit`
# typed now ends terminal 2's shell and closes it, and the keys come back
# to the first, where `exit` refuses. Super+Enter on a keyboard opens
# another. The compositor killed, both windows come back. Screenshots
# along the way (terms-one, terms-two, terms-back).
# Run: QEMU_INPUT=tools/shell-tests/terms-windows.txt \
#      QEMU_USB="-device usb-kbd,bus=xhci.0,port=2" tools/qemu-test.sh build/test terms-windows shell comp
wait 120 Jam OS shell
seen 10 console: window mode: terminal 1 opens a
wait jam>
sleep 2
shot terms-one
send term
wait 10 terminal 2 opens
wait 30 Jam OS shell
wait 10 jam>
seen 30 console: window mode: terminal 2 opens a
sleep 2
shot terms-two
send exit
wait 10 init: terminal 2: its shell ended with exit
wait 10 init: terminal 2 is closed
sleep 1
send exit
wait 10 exit: this is the first terminal
wait jam>

monitor sendkey meta_l-ret
wait 10 init: terminal 2 opens
wait 30 Jam OS shell
wait 10 jam>
sleep 1
send kill compositor
wait 10 init: bin/compositor was killed
wait 30 console: connected again (connection 2)
wait 30 console: connected again (connection 2)
sleep 3
shot terms-back
send echo "ok-""back"
wait 10 ok-back

send reboot -f
wait reboot: resetting
