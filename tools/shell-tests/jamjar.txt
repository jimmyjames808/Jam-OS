# ---- 3: the mouse ------------------------------------------------------------------------
# Each target is reached from the top-left corner (the pointer is clamped
# there), a pixel a count. QEMU's mouse sends at most 127 counts a report
# and merges moves not sent yet, so each move gets time to arrive before
# the next. The next button's middle is (1064,411).
monitor mouse_move -3000 -3000
sleep 1
monitor mouse_move 1064 411
sleep 0.6
monitor mouse_button 1
sleep 0.15
monitor mouse_button 0
wait 10 jamjar: click 1064,411
wait jamjar: next
# the volume slider (770..998 x 467..479): a drag from 900 to 840
