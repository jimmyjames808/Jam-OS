# The boot splash on the compositor (a plain boot, booted with it:
# tools/splash-test.sh): it plays in a full-screen window that takes no
# keys, over the first terminal's window, which keeps them. A line typed
# while it plays, one typed once it has played and one right after its
# window is gone all reach the shell once it is up, which runs them (the
# second prints typed-kept: the variable the first set). Screenshots: 12
# from init's start, 0.1 s apart, each the dark screen or a frame of the
# video (the compositor shows only the splash's background until the
# splash's window maps: no desktop, terminal or pointer before it), two
# frames a second apart, then the terminal. Then the splash's self-test
# and its alpha demo (`run splash --alpha`, a full-screen window) from the
# shell.
wait 120 init: hello from ring 3
shots comp-early 12 0.1
wait 120 splash: waited
shot comp-a
send K=kept
sleep 1
shot comp-b
wait 60 splash: played at
send echo typed-$K
wait 60 init: bin/splash exited with code 0
send echo right-""after
# (the shell may run the first two before the splash has gone: `seen`)
seen 60 typed-kept
wait 60 right-after
wait {prompt}
sleep 1
shot comp-shell
send run splash --selftest
wait 240 splash: selftest
wait 240 run: bin/splash exited
wait {prompt}
send run splash --alpha
wait 60 splash: alpha demo drawn
sleep 1
shot splash-alpha
wait 60 run: bin/splash exited
wait {prompt}
send reboot -f
wait reboot: resetting
