# The mouse, end to end: run by tools/mouse-test.sh (QEMU_USB = a usb-kbd
# on xhci port 2 and a usb-mouse on port 3; the command line "shell", at
# OVMF's 1280x800). QEMU's monitor moves the mouse and presses its buttons
# (`mouse_move dx dy [dz]`, `mouse_button <bits>`: 1 left, 2 right); the
# reports go usb-bus -> drv/hid -> console, and from there only to a
# focused client that asked for them.
#
# The client that asks is `wltest --mouse` (user/tests/wltest/fun.c),
# which goes through libfun as an app does: under `nocomp` the console's
# screen and key channel, and libfun's pointer (user/apps/fun/mouse.c),
# which makes a position out of the relative counts. It says every edge on
# the console: "wltest: mouse: left down at X,Y", "... left click at X,Y"
# (or "drag from X,Y to X,Y"), "... chord at X,Y", "... wheel +1 at X,Y".
# The pointer starts in the middle of the screen, (640, 400) at 1280x800,
# and is put somewhere exact by pushing it into the top-left corner (it is
# clamped there) and moving on from (0, 0); `noaccel` makes a count a
# pixel.
wait 120 Jam OS shell
wait {prompt}
# "report mouse ready", or with hidboot "boot mouse ready" (mouse-test.sh
# checks which).
seen 30 mouse ready
# The shell never asked for the mouse: moving it, clicking and turning the
# wheel sends it nothing (its line editor would misread any message), and
# the wheel scrolls the console back as before.
send help
wait Commands:
wait {prompt}
monitor mouse_move 60 -40
monitor mouse_button 1
sleep 0.2
monitor mouse_button 2
sleep 0.2
monitor mouse_button 0
monitor mouse_move 0 0 1
monitor mouse_move 0 0 1
sleep 0.7
shot mouse-scrollback
send echo mouse-$HOME
wait mouse-/
wait {prompt}
# An app that didn't ask for the mouse (`wltest --mouse nomouse`) reads
# its keys undisturbed under a busy mouse: only the two keys typed reach it.
send run wltest --mouse nomouse
wait run: bin/wltest started
wait 30 wltest: mouse: ready
sleep 1
monitor mouse_move 200 100
monitor mouse_button 1
sleep 0.2
monitor mouse_button 0
monitor mouse_move -90 40 1
type x
sleep 0.5
type q

wait run: bin/wltest exited with code 0
wait {prompt}
