# The boot disk with two Jam OS sticks in (tools/bootdisk-test.sh): the
# one the machine booted from (OVMF boots the stick on port 1) is /esp and
# /data, whichever answers first; the other, with another MBR disk id and
# other-stick.txt on its data partition, is mounted read-only as /usb0
# (its ESP) and /usb1 (its data). Then the same after a kexec reboot,
# whose kernel learns the disk id from the kernel before.

wait 60 is the boot disk

wait 60 partition 2 is /usb1
sleep 1
send ls /data
wait {prompt}
send ls /usb1
wait 30 other-stick.txt
wait {prompt}
send reboot
wait 120 from the kernel before
wait 60 is the boot disk
seen 60 the machine booted from another disk: not the boot disk
wait 60 partition 2 is /usb1
sleep 1
send ls /usb1
