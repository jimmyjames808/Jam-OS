# TCP end to end (tools/tcp-test.sh runs this): a plain boot with QEMU's
# e1000e and the network peer, net.address set in the stick's settings.
# bin/tcptest connects to the peer's TCP server (tools/tcppeer.py, on the
# Mac's address) and sends 10 MiB, reads 10 MiB back, every byte checked
# on both sides; the same with 8 MiB and 2 MiB rings (a scaled window) to
# a server whose ACKs come 20 ms late; then it listens on port 5031 and
# serves the peer's 20 connections at once from one wait set, 256 KiB
# each way each. The script checks the peer's counts afterwards.
wait 120 Jam OS shell
seen 60 netstack: link up
seen 30 netstack: address 10.2.21.5/24
wait {prompt}
send run tcptest send 10.2.21.174 5030 10485760
wait 300 tcptest: PASS: connected
wait {prompt}
send run tcptest send 10.2.21.174 5032 8388608 2097152
wait 300 tcptest: PASS: connected
wait {prompt}
send run tcptest serve 5031 20 262144
wait 30 tcptest: listening on port 5031
wait 300 tcptest: PASS: served 20 connections
wait {prompt}
send net stats
wait {prompt}
send reboot -f
wait reboot: resetting
