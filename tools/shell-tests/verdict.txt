# A shell script's verdict on a failing utest (tools/verdict-test.sh, which
# puts the mode in place of @MODE@ and checks that this script fails, or
# passes, as that mode should):
#   ok      utest's verdict_canary passes (the control)
#   fail    it fails a check: "utest: 0 passed, 1 FAILED"
#   crash   it faults: utest is killed and gives no summary
# The script is written the weak way on purpose, as audio-api.txt and
# posix-procinfo.txt were: nothing here looks at the summary line or at $?
# (the echo is a constant), so only tools/serial-feed.py's verdict can fail it.
wait 120 Jam OS shell
wait {prompt}
send export UTEST_CANARY=@MODE@
wait {prompt}
send utest only verdict_canary; echo vd-""1
wait vd-1
wait {prompt}
send reboot -f
wait reboot: resetting
