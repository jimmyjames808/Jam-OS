# Programs that draw with libfun on the screen they borrow, from the
# shell: run by tools/apps-test.sh (QEMU_USB = a usb-kbd on xhci port 2
# and a usb-mouse on port 3; the command line "shell nocomp", so they
# borrow the console's screen: tools/shell-tests/wlapps.txt has them as
# windows). The self-tests of the test programs fractal (user/tests/fractal:
# its maths, the parallel render, libfun's pool) and wltest (libfun's
# pointer); then fractal explored through the serial terminal (arrows arrive as ESC [ A..D,
# letters as themselves) with screenshots (<name>.png next to the log),
# its benchmark, quit with q, and the shell prompt must come back: the
# console redraws its text screen when the lease closes. wltest's mouse
# mode (user/tests/wltest/fun.c) before the mouse stirs and with one click;
# then a program killed (Ctrl+C: the shell kills its job) and one that
# crashes (a page fault) with the screen still borrowed. Nothing here
# depends on the screen's size, so the same script runs at 1280x800 and at
# 2560x1440 (APPS_HD=1): the one mouse click is at the pointer's starting
# place, the middle of the screen. tools/shell-tests/mouse.txt drives the
# mouse further.
wait 120 Jam OS shell
wait {prompt}
seen 30 report mouse ready
send run fractal --selftest
wait 240 fractal: selftest PASSED
wait run: bin/fractal exited with code 0
wait {prompt}
send run wltest --selftest
wait 60 wltest: selftest PASSED
wait run: bin/wltest exited with code 0
wait {prompt}
# fractal: the whole set, a famous place, a Julia set in another palette,
# then deep: the tour's point zoomed 2^60 (~1e18x: perturbation); the
# benchmark (one CPU against all of them) on the way
send run fractal
wait run: bin/fractal started
sleep 8
shot apps-fractal
type 2
sleep 12
shot apps-fractal-seahorse
type b
wait 120 fractal: benchmark,
type jc
sleep 10
shot apps-fractal-julia
type j1tt++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
sleep 40
shot apps-fractal-deep
type q
wait 30 renders on
wait run: bin/fractal exited with code 0
wait {prompt}
# wltest's mouse mode: before the mouse stirs, then one click where the
# pointer starts
send run wltest --mouse noaccel
wait run: bin/wltest started
wait 30 wltest: mouse: ready
sleep 1
shot apps-wltest-no-mouse
monitor mouse_button 1
sleep 0.2
monitor mouse_button 0
wait 10 wltest: mouse: left click at
sleep 0.5
shot apps-wltest-click
type q
wait 30 wltest: mouse: 1 clicks (1 left
wait run: bin/wltest exited with code 0
wait {prompt}
# Ctrl+C in a program that reads its keys quits it (the shell would kill
# it too)
send run fractal
wait run: bin/fractal started
sleep 3
type \x03
wait 30 run: bin/fractal
wait {prompt}
# Killed with the screen borrowed: a program that reads no keys, Ctrl+C
# (the shell kills its job; the lease closes with it)
send run wltest --hang-test
wait 30 wltest: hang test: holding the screen
sleep 1
shot apps-hang
type \x03
wait 30 run: bin/wltest was killed
wait {prompt}
# ... and a crash: a program that dies (page fault) holding the screen
send run wltest --crash-test
wait 30 run: bin/wltest was killed
wait {prompt}
# the shell is back in charge of the keys and the screen
send help
wait Commands:
wait {prompt}
sleep 0.5
shot apps-shell-after
send reboot -f
wait reboot: resetting
