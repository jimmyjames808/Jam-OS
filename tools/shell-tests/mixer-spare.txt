# The mixer's warm spare (user/services/init/spare.c); use
# tools/mixer-spare-test.sh (it adds the sound card and checks the log).
# A spare waits from the boot; `ps` shows it next to the mixer; `kill
# mixer` promotes it (said with the time it took and the kill to the first
# answer) and a new spare starts; twelve kills in a row are never given up
# (a deliberate kill doesn't count); `kill devmgr` makes the mixer end by
# itself (a crash, as init counts it), which is restarted at once from the
# spare once devmgr is back. The mixer answers after each.
# (The markers are echoed as sp-""1 so the typed line itself never matches.)

wait jam>

wait sp-1
