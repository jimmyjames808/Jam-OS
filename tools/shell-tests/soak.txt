# The soak test from the shell, short: `soak loops=2` (each loop: the kernel
# tests in a shuffled order under the kernel's load, then utest; bin/soakload
# writes and reads files meanwhile), and its SOAK RESULTS box. No sticks are
# pulled here: tools/soak-test.sh does that (soak-plug.txt).
# QEMU_INPUT=this file, command line "shell", QEMU_TIMEOUT=600.
wait 120 Jam OS shell
wait jam>
seen 60 init: /data mounted
send soak loops=2 seed=11
wait 30 soak: begun on
wait 400 ktest: loop 1 of 1 done
wait 200 utest:
wait 400 ktest: loop 1 of 1 done
wait 200 utest:
wait 200 SOAK RESULTS
wait soak: PASSED after
wait shell: soak: PASSED
wait jam>
send reboot
wait reboot: resetting
