# More terminals (docs/G1-PLAN.md, track T1): on a plain boot init starts
# the compositor before the console, and each console
# runs in window mode (a window of the compositor's once it offers
# xdg_wm_base; without one, its text goes to COM1 only). `term` opens
# terminal 2, a console and a shell of their own (its output is copied to
# COM1 too, so its banner shows here). Its shell and its console killed
# are started again, as the first terminal's are; the compositor killed,
# both consoles connect again; the first terminal answers throughout.
# Then terminals up to the limit (8 in all), and `term` refuses one more
# (each `term` typed once the last one's window is up and has the keys).
# Screenshots: terms-boot (the first terminal), terms-eight (all eight).
# Typing into terminal 2 and closing it (`exit`, its close circle):
# terms-windows.txt and desktop.txt.
# Run: QEMU_INPUT=tools/shell-tests/terms.txt tools/qemu-test.sh build/test terms shell
